=====================================================================
v2.0.3.55  -  storage safety, private data, smarter notifications
=====================================================================
STORAGE / RECEIPTS
 1. Receipts are downscaled and recompressed on capture (was 1400px@85%,
    now 1080px@72%) - typically 4-6x smaller per receipt.
 2. Receipt images now live in a dedicated IndexedDB vault instead of the
    single settings blob. Existing receipts migrate automatically on launch.
 3. saveDB() no longer fails silently. If the browser refuses a write the
    app now says so and compresses receipts to reclaim room. Previously a
    full store meant every later change was lost with no warning.
 4. Orphaned receipt images are cleaned up after a delete.

RECEIPT CROPPER
 5. New pinch-zoom / drag cropper for receipts under a fixed mask, matching
    the smooth profile-photo cropper. The old four-handle frame is gone.
 6. Back gesture closes the cropper instead of the app.

PRIVACY / SECURITY
 7. The PIN is no longer stored in readable form. It is kept as a salted
    PBKDF2-SHA256 hash (150k iterations); existing PINs migrate silently on
    first launch. The PIN is never written to a backup.
 8. Backups are encrypted with AES-256-GCM, keyed from your PIN. New file
    extension .mmbak.
 9. Restoring is PIN-gated. A backup from another Money Map cannot be
    decrypted without its PIN, and a foreign file is called out before it
    can replace your data.
10. Unencrypted backups still restore (your choice) but now warn first.
11. Receipts are carried inside the encrypted backup.

NOTIFICATIONS
12. Weekly insight now compares this week against last week, names the
    biggest category and flags a genuine spike.
13. New mid-month outlook (15th, 18:00) projecting month end from your real
    daily spend rate, saying whether money should carry over or run short.
14. The empty-day reminder is persuasive instead of generic.
15. Tapping a notification lands on the matching screen and the alert
    explains itself in Analytics / Remaining income.

DARK MODE
16. Samsung-style dark theme: pure black canvas, neutral dark grey cards,
    no gold glow on the four main cards.

  - notification-bar icon size
  - launcher icon colour
