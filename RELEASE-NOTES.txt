Money Map v2.0.3.65 - web files only

Replaces Money_Map.html and sw.js. No APK rebuild needed for these seven.
The v2.0.3.64 Android source still needs its own upload and APK build for the
launcher colour, icon size, live notifications and native back.

1. REMAINING INCOME - the line is gone and the amount now works.
   Root cause: my helper called cur(v) expecting a money formatter, but the
   app's global cur() takes no argument and returns only the currency CODE.
   That is exactly why it read "about UGX spare" with no figure. It now uses
   fmtShort, the app's real formatter, and a digit test makes it impossible
   for a bare code to reach the screen again. What is left is one short line.

2. SUMMARY CARD NOW ACTUALLY PINS.
   Root cause: the summary was pinned at top:0, but the list sits below a
   .sticky-head that is itself pinned at top:0 with a higher layer - so the
   card was pinning underneath the header where you could never see it. The
   header height is now measured live and the card pins just below it, on all
   four tabs, with the list passing under it.

3. EXPANDED BUDGET CARD - the three boxes and the "On track - 93%" line are
   gone. Both repeated the header and the ring. The transaction heading now
   names the period: "Aug 2026", or just "2026" when a whole year is selected.

4. EXPANDED ASSET CARDS - the inner boxes are gone on all three kinds:
   physical assets, cash accounts and investments. Each only restated the
   figure already on the card header.

5. SETTINGS - the app-lock paragraph is one line instead of four, and every
   settings screen now carries a short one-line explainer.

6. IMAGE PREVIEW - tapping the picture again no longer blanks the screen.
   The full image opens first and the round preview retires underneath it,
   instead of closing 180ms before the full view opened. Fixed on the shared
   handler, so it applies from the overview and from settings.

7. WELCOME LINE - "UGX still unspent within 4 days to go" is replaced with a
   real reading, including what is left and roughly what that allows per day
   for the days remaining, or a clear note when income is fully committed.
